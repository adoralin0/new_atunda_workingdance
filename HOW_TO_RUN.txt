How to open the Atunda website
==============================

Repo / website folder:

  C:\Users\adora\new_atunda_workingdance

Do NOT double-click index.html.
Browsers block Unity WebGL on file:// URLs.

Steps:
1. Open PowerShell
2. Run:

   cd C:\Users\adora\new_atunda_workingdance
   python -m http.server 8000

3. Open in your browser:

   http://localhost:8000

Keep the PowerShell window open while you use the site.
Press Ctrl+C in that window to stop the server.

Unity WebGL rebuild tip
-----------------------
When you rebuild from Unity, build into this same folder
(new_atunda_workingdance), not new_atunda_working_dance_2.

Unity names Build files after the output folder. If files come out as
new_atunda_working_dance_2.*, either:
- rename them to new_atunda_working_dance.*, or
- update the four paths in game.js to match.

game.js currently expects:
  Build/new_atunda_working_dance.loader.js
  Build/new_atunda_working_dance.data
  Build/new_atunda_working_dance.framework.js
  Build/new_atunda_working_dance.wasm
